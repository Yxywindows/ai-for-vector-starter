## 3. 时间线、选面与 DOM 锚点

| 相位 | 实际时长与行为 |
|---|---|
| idle | 仅魔方持续旋转；角速度 `0.45 + 0.2 sin(πt/4)` rad/s，范围 0.25–0.65，周期 8 s；小G 播放原 Idle |
| focusing | 从当前可见 quaternion 出发，以 smoothstep 在 510 ms 内对准目标面；不会先复位魔方 |
| reveal | 300 ms 开始、至 850 ms 稳定；投影四角从所选面角点生长至本断点阅读区 |
| Frame 0 / 30 / 90 / 180 | 点击后的 0 / 500 / 1500 / 3000 ms。F90/F180 为观察点。850 ms 后保持预览，绝不自动展开 |
| expanding | 用户点击“展开工作台”后新 560 ms；投影展平至工作内容范围，小G向页首缩进；独立标题锚点按原字号移向目的页标题，避免整块文字随平面膨胀 |
| work switch | 内容即时切换，160 ms 轻微淡入；不重新旋转魔方或重建 Canvas |
| return / history | Esc/返回即时恢复首页与入口焦点；浏览器后退恢复对应 preview/work 状态。深链直接进入目的页 |
| reduced motion | 直接落在可用终态，旋转与 Idle 停止。停止后的场景不持续渲染 |

| 功能 | 本地法线 | 原资产节点 |
|---|---|---|
| 项目空间 | +Z `[0,0,1]` | Face_projects |
| 数据资源 | +X `[1,0,0]` | Face_data |
| 空间分析 | −Z `[0,0,-1]` | Face_analysis |
| 任务进度 | −X `[-1,0,0]` | Face_tasks |
| 导出交付 | +Y `[0,1,0]` | Face_exports |
| 平台概览 | −Y `[0,-1,0]` | Face_overview |

`scene.mjs` 是唯一逐帧写入相机、魔方与投影的模块。面中心为魔方中心加世界法线 × 0.216 × cubeScale，其中 0.006 是名义表面外的防重叠偏移；两个切向量来自所选面的本地正交基并随真实 quaternion 变换。连接线和透明窄面都引用这些真实面角点。QA 记录世界法线点积、来源屏幕点、四角和面偏移。

投影终点按阅读安全区取得屏幕四边形，以相机射线与面平面相交，生成同场景边界；8 元方程求 homography，写 `#projection` 的 matrix3d。`#preview-title`、项目与图层信息、小范围 SVG、展开按钮均为可选中 HTML。桌面常规阅读平面宽不超过 380 px、高 510 px；窄横屏 260×296，并缩减重复说明。

手机连接面留在角色右侧，终点接向下方文档流；不铺一大块透明面穿过脸、胸或 OpenGMS 标志。下方预览不承担桌面矩阵缩放，保持触控与阅读尺寸。

`transitionId` 淘汰过期展开回调。快速点击从当前姿态转向最新选择；Esc、返回或 history 会清理等待中的展开。预览不是 modal，不锁焦点。展开后焦点到工作标题，返回到发起入口；真实表单与滚动立即可用。
