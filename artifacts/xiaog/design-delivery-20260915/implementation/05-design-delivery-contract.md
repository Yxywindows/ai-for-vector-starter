## 2. 画幅与信息结构

首页是一个完整场景。小G占主亮部；魔方身侧悬浮；有真实项目依据的地图片位于前景；导航在边缘，短标题和对白占安静留白。明暗、遮挡、尺度与短距离镜头组织注意力，避免巨型宣传语、玻璃卡堆叠、随机粒子和霓虹 HUD。

桌面以 1440×900 为主标尺，并验证 1920×1080。首屏小G约有效视高 52–60%，最终以实际模型脸、胸标、魔方可见和负空间为准；数值不是强迫所有断点同样取景。390×844 重新取景，脸胸和魔方位于上部约 320–380px，下方内容正常文档流；窄横屏优先内容高度。触控目标至少 44px，触屏不加指针视差。

| 页面 | 主信息与操作顺序 | 连续对象 | 空/错态与边界 |
|---|---|---|---|
| 项目空间 | 可搜索项目列表 → 显式选择 → 项目图层/范围摘要 → 打开地图 | 项目 id、名称、选择位置 | 无项目提供创建入口设计；无范围显示“暂无空间范围”，不用虚构地图。悬停只预览，不更改工作项目 |
| 项目详情 | 项目名 → 图层列表 → 来源/范围 → 进入地图 | 项目及合法返回位置 | 详情失败不改选其他项目；删除行为仍属于后续正式业务实现 |
| 数据资源 | 搜索/类型/项目筛选 → 目录 → 所选数据详情与空间范围 | layerId、筛选、明确的所属项目 | 未注册 PostGIS 表保留独立身份，无 layerId 不提供假详情/地图定位 |
| 数据详情 | 概览、字段/属性、样式、来源与空间范围分区 | 当前图层及项目 | 字段/属性/样式保留原有能力；不存在的图层给出返回目录入口，不默默选下一层 |
| 空间分析 | 项目/输入图层 → 方法 → 参数 → 提交状态 → 真实作业/结果 | 输入图层、工具、taskId、result.layerId | 七种工具依据当前 AnalysisPage；未运行无结果，出错保留参数与重试上下文 |
| 任务进度 | 全部/当前项目、类型/状态筛选 → 时间列表 → 日志 → 可用结果 | taskId、任务自带 projectId/layerId | 只展示已取得的状态；不估造百分比。无结果无下载；失败优先呈现错误和实际可用操作 |
| 导出交付 | 项目/图层 → 合法格式与字段/CRS → 文件名 → 提交状态与交付记录 | 图层、格式、导出 taskId | 矢量 GeoJSON/GPKG/SHP/CSV；栅格 GeoTIFF；当前页面没有任意框选裁剪，不新增该承诺 |
| 平台概览 | 全局总量一行 → 近期项目/数据索引 → 打开对象 | 全局统计与最近对象 | 不把全局视图隐式过滤成一个项目；统计失败和真正零值不同 |
| 地图工作区 | 图层/地图/属性表 → 明确对象操作 → 编辑/样式/任务状态 | 项目、view、sel、编辑队列 | 保留正常 GIS 手势、数据颜色、错误、滚动和现有布局能力。陪伴头像不能遮要素与工具 |

六个主要目的页须在 D01 原型中可查看、可切换；项目/数据详情可由主从区或详情抽屉覆盖。地图工作区至少交付可查看的设计画面，包含图层区、地图、属性表/编辑工具、小G安全区及未保存编辑离开的分支；可以独立设计页呈现。复杂编辑不必在原型里接入生产能力，不能声称已集成既有编辑器。

## 3. 正式 URL 与上下文决定

以下为后续实现的确定契约，**不是当前源码已支持的行为**。当前路由见 [router.tsx](C:/Users/yxy/Desktop/work/AI_FOR_VECTOR/web/src/app/router.tsx)，当前 Analysis/Exports 仍存在回退首个项目的逻辑，正式重构时按此替换并专项验证。

| 对象/字段 | 权威来源与写入时机 | 校验与失效处理 |
|---|---|---|
| 页面路径 | 保留 `/projects`、`/projects/:projectId`、`/data`、`/data/:layerId/*`、`/analysis`、`/tasks`、`/exports`、`/overview`、`/projects/:projectId/map` | 未识别路径沿用有出口的路由错误/首页处理，不由动画 store 创造第二套路由 |
| `projectId` | 对项目路径以 path id 为准；分析/导出等非项目路径以显式 query 为准。用户选择项目后写 query | 验证存在；path/query 冲突时 path 胜出并清除冲突 query。没有显式选择且没有有效继承时显示选择器，不偷偷选第一项 |
| `layerId` | 对数据详情以 path id 为准；其他页使用 query，或来自明确对象操作 | 取得图层再检查所属项目与功能可用性；跨项目冲突清除所选图层并提示。切换项目清空相关输入/结果引用 |
| `taskId` | 来自明确任务选择或真实提交结果，可作为 query | 以任务返回的 projectId/layerId/结果为准，不能从动画推测。任务被删除/不可读时显示状态并保留列表入口 |
| `returnTo` | 进入功能页前保存来自同一项目的合法内部地图 URL，包括现有 view/sel/drawer | 只允许同源内部 `/projects/:id/map` 目标，拒绝外域、协议相对、脚本、递归 returnTo；项目不匹配或参数无效时退回该项目地图入口，不跨项目恢复 |
| 地图 `view`、`sel` | 继续使用既有 `view=z/lon/lat` 与 `sel=layerId:fid,…`，地图操作 replace URL，正式页面切换 push | 使用既有 parseViewParam 范围与有限值检查；另验证所选图层归属。同项目 query 变化必须被地图正确消费，不能只在首次挂载读取 |
| 目录/任务筛选 | 列表自身 URL/query 或受控局部状态，返回时恢复同一列表状态 | “全部”是显式有效范围。没有绑定的表不能被赋予虚假项目；恢复筛选不触发业务提交 |

继承顺序：当前显式目标 → 同一次用户导航携带且验证通过的上下文 → 同标签页内有效的最近上下文 → 选择器。直接深链不被最近上下文强行覆盖；本地 lastProject 只能作可见建议，不能成为静默操作目标。项目/数据/任务读取错误保留原目标并显示错误，不回退其他项目。

数据归属保持 TanStack Query。舞台状态只存功能 id、过渡 id、相位和轻量显示引用；不复制全部项目/图层或把 Query 结果放进逐帧动画状态。原型若用 hash 或设计快照，交接必须明确与这些正式 URL 的映射。

## 4. 镜头与 DOM 的协作契约

| 阶段 | 目标与时长 | 可打断行为 |
|---|---|---|
| idle | 相机静止，小G Idle，魔方平滑变速，导航已可用 | 导航不等模型；模型失败用同资产静态画面 |
| focusing | 当前姿态连续对准选中面，约 400–550ms | 新选择从当前可见姿态转向新目标；旧 transitionId 完成回调无效 |
| reveal/preview | 面轮廓延伸为空间切片，约 300–450ms，和聚焦尾段衔接；合计约 800–900ms 稳定 | 数据等待与镜头分开；预览稳定后无限等待用户。F90/F180 为观察点，不额外锁操作 |
| expanding | 用户点击后 450–650ms，切片展平并对齐内容区域；标题保留共同基线 | 不穿过魔方/脸部；导航/取消有确定结束状态；路由内容失败时有可操作错误页 |
| active | 实际内容接管，小G页首陪伴，业务内快切约 120–220ms | 表单与滚动即时可用，不重复主场景过场 |
| returning | 沿相同空间轴返回或在历史/深链时短淡入 | 恢复菜单焦点与有效上下文，不强制倒放完整电影 |

面朝向遵从 T02：projects +Z、data +X、analysis −Z、tasks −X、exports +Y、overview −Y。每次计算目标四元数，使当前功能面的世界法线对向观察方向；不要每次先复位 cube。投影起始角点来自选中面变换，终点由当前断点的可读区域决定。相机、魔方、投影锚点由单一时间轴写入，不由 CSS/GSAP/useFrame 竞争同一属性。

全站只需一个受控角色 Canvas。对白、标题、操作和业务内容保留 HTML；投影可有 WebGL 边界与 HTML 文本，但必须同步位置和可见性。缩入页首可用同 Canvas 的视口/对象变换或静态头像，不能偷偷新建第二 Canvas。静态/减少动态路径直接落在可用终态，不能依赖动画结束事件。

对白是局部柔和暗幕上的文本，不是聊天组件。只在必要状态改变时 polite 播报；没有逐字打字和持续重复播报。预览不是 modal，不锁全页焦点；展开后焦点到目的页标题，取消/返回回到发起的菜单项。

## 5. 地图、编辑与性能边界

- [WorkspaceSync.tsx](C:/Users/yxy/Desktop/work/AI_FOR_VECTOR/web/src/map/WorkspaceSync.tsx)现有缩略图仅 256×128，并在地图 moveend/rendercomplete 后延迟 PUT。舞台动画不能调用这条写链；原型读取数据后以本地快照演示，不触发缩略上传。
- 地图仍在 lazy route 中加载。首页范围/小量几何示意不应 import OpenLayers、ag-grid 或整个地图编辑器。真实投影/比例尺未建立时，不把范围图标成精确测量地图。
- [useEditSession.ts](C:/Users/yxy/Desktop/work/AI_FOR_VECTOR/web/src/features/editing/useEditSession.ts)按 layerId 创建本地 EditQueue。相机与界面动画不能导致该组件或图层重新挂载。正式地图阶段要给离开项目/切换编辑图层设计“保存并离开 / 放弃并离开 / 继续编辑”分支：保存失败保留队列与页面；没有 pending 时不打扰。当前未发现统一路由离开保护，不能声称已有自动草稿恢复。
- [editSession.ts](C:/Users/yxy/Desktop/work/AI_FOR_VECTOR/web/src/features/editing/editSession.ts)逐条 flush，失败留队列；不要在设计中宣称原子事务。减少动态、切换陪伴显示和菜单预览不执行 save/discard。
- 桌面初始 DPR 封顶 1.5，低档 1；不靠实时体积雾、Bloom、景深、反射才能成立。地图工作时优先其交互，停止背景持续更新或用静态陪伴。
- 记录真实设备/视口/DPR/资产哈希/帧时间与帧长任务。连续样片不等同实时性能测试；设计包可运行不等同生产 GIS + WebGL 负载验收。
