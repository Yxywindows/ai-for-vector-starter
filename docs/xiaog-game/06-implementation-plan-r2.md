## T04：真实空间主场景与上下文基础

**负责模型：Astra。** 这一步包含跨路由上下文与 WebGL 生命周期，不能把核心决定留给分散的页面实现。

输入：D01 最终构图/灯光/token/镜头参数、T02 runtime_manifest 与小型运行时文件、主目录最新 T03 代码、05 的 URL 合约。

修改范围：experience 的单 Canvas 场景、模型加载/资源释放、朝向与待机控制、共享上下文解析/链接构造、必要错误与降级组件；仅复制运行时 GLB/头像/许可到 web/public 约定目录。新增 Three/R3F 等依赖需锁定实际版本并验证与当前 React；不升级 GIS 或整套依赖。

实现决定：

1. 先拆出轻量上下文解析与链接构造，测试 path/query 优先级、项目/图层归属、returnTo 白名单和失效规则。数据仍归 Query；没有显式目标时显示选择器，不复用 Analysis/Exports 的首项目回退。
2. 单场景先落地 idle/focusing/preview 静态终点，与相机/魔方共用一个写入者。真实六面法线参与对准，初始姿态与旋转速度连续，不复位跳转。
3. 加载 UI/链接立即可用。角色与魔方可独立失败，正确释放几何、纹理、材质与事件；WebGL context lost 可回退静态画面。页面隐藏暂停更新，减少动态直接终态。
4. 首页仅取选中项目轻量范围/摘要；不能为了地图前景加载 OpenLayers、ag-grid 或全部项目详情。

验收：真实 GLB 哈希与面节点一致；正常/失败/减少动态都可导航；六面朝向和稳定停止、连续切换、StrictMode 重挂载/离开后的资源清理；包分析保持地图 lazy。审阅实际 diff 后运行相关 reducer/context/场景测试、lint/typecheck/build 和实际浏览器检查。没有生产 FPS 证据不宣称 60fps。

## T05：融景对白、投影展开与导航闭环

**负责模型：Astra。** 输入为通过复核的 T04 和 D01 时间线/关键帧。

范围：ExperienceRoot、reducer、motionConfig、投影 HTML 锚点、陪伴位置、导航预取/焦点与取消；保持业务页面内部语义。

实现决定：

1. 使用真实镜头/朝向完成信号驱动相位，transitionId 丢弃过期回调；加载状态独立于动画。800–900ms 稳定预览后等待用户，F90/F180不是硬等待。
2. 从对应魔方面投出同项目/图层内容，文字位于可读区域；450–650ms 展开沿同一空间轴接到内容区域，小G收至页首。无第二 Canvas。
3. 旧 preview 在新目标确认时立即失效；新选择从当前视觉姿态继续。Esc、导航、模型失败、浏览器返回或路由错误都落在确定可操作状态。
4. 对白只解释当前操作，真实成功后才播报成功；不新增聊天后端。进入目的页焦点到标题，取消回菜单；预览不是焦点陷阱。
5. 深链直接进入业务；业务页间快切不经过魔方。用上下文链接携带有效 project/layer/task/returnTo，数据失败不替换目标。

验收：六入口完整闭环、快速连点、展开中取消、取消后旧回调、浏览器前进/后退、深链和错误页、项目切换、键盘与减少动态。实际录像包含停顿与用户点击；截图和测试不能替代连续观察。

## T06：六个目的页与详情的实际业务接入

**Astra 先确认公共上下文与数据边界，明确页面布局可由 Luna Max 实施；Astra 审阅合并后的 diff。** 不让各页自行设计新的全局 store 或首项目回退。

范围：Projects/ProjectOverview、DataCatalog/DatasetDetails、Analysis、Tasks、Exports、Dashboard 与公共页面样式。基于 D01 页面结构，保留真实表单、Query、错误状态和当前业务 API。

逐页要求：

- 项目：列表选择与范围对应，显式打开详情/地图；保持项目路径权威。首屏不无界请求每个项目详情。
- 数据：搜索/类型/项目范围可恢复；未绑定 PostGIS 表是独立条目，不能以名字相似认定 layerId 或归属。字段、属性、样式各标签保留既有能力。
- 分析：接入共享 projectId/合法 layerId，切项目清空相关输入；保留 buffer、clip、intersection、dissolve、spatial-join、validate-repair、point-in-polygon。单位、次输入需求、错误和结果引用以当前 API 为准。
- 任务：全部与项目范围清楚，状态/类型/分页/日志、取消/重试和可用结果保留；任务提示不能推断成功、比例或持续时长。
- 导出：矢量支持既有四格式、字段与 CRS；栅格单独 GeoTIFF。下载只在真实任务具备有效结果时可用；本阶段不扩大为任意地图裁剪功能。
- 概览：全局统计与近期索引，真实零值/加载/错误可区分，不能受最近项目静默过滤。

验收：既有页面/API语义测试继续通过，增加上下文跨页、空/错/未绑定表、七分析工具有效提交参数、矢量/栅格导出和任务操作必要验证；用户写操作只在明确授权测试数据范围执行。桌面/手机/长内容实图复核，主语言中文，地图数据颜色不被主题改写。

## T07：地图工作区、返回状态与性能

**负责模型：Astra。** 输入为 T04–T06 验收后的累积基线；独立审阅地图、URL 与编辑队列生命周期。

范围：App、AppShell/地图壳、WorkspaceSync、MapProvider、相关编辑退出保护及小G陪伴策略。避免顺手重写图层工厂、缓存、算法或数据库。

实现决定：

1. 地图继续单个活动 OL 实例与 lazy 边界。舞台相机不触发地图 fit/moveend/缩略上传，DOM字幕/菜单与地图拖拽事件分流。
2. 合法 returnTo 恢复项目/view/sel/drawer；同项目 query 更新与切项目分别处理，不只 mount 时读一次。用户拖动立即 cancelAnimations。
3. 正式接通 pending 编辑离开保护；保存失败保留剩余队列，放弃必须来自用户选择。场景缩放、陪伴隐藏、减少动态不能销毁队列或自动保存。
4. 地图忙时静态陪伴，停掉不必要 3D 更新。按设备/视口/DPR记录 GLB+地图同时工作的帧时间、长任务、资源与导航响应；据此确定默认档位。
5. 无高清截图管线时使用范围示意接续真实地图，不扩大 256×128 缩略图，也不宣称已保存 Project.view。

验收：项目之间/同项目返回、地图平移缩放/定位中打断、图层选择/样式/表格/布局、未保存编辑保存/失败/放弃/留在页、地图与舞台加载失败、资源释放、低档与手机横竖屏。性能验收在实际同时负载下，不用离线视频帧率替代。

## T08：整体验收、修复与交付

**负责模型：Astra。** 不新增功能，以实际 diff、源文件和端到端证据判断完成。

1. 核对全部累积改动、资产许可证/哈希、旧占位文案与引用；确保没有 Snow、概念图或旧设计误接入。
2. 修复审阅发现的问题，再运行完整 lint/typecheck/tests/build；后端未变不盲目跑迁移。保护原有本地数据与用户文件。
3. 实际浏览器覆盖六入口/六目的页/详情/地图/返回、数据和模型失败、空项目/无范围/未绑定表、快速切换/取消、键盘/减少动态和三个目标画幅。
4. 输出运行中的完整新前端、可复跑构建与启动说明、完整流程录像/关键帧、最终资产清单、具体测试结果与剩余限制；区分本地验证与部署、业务验收。
5. 每个阶段 ready 必须来自检查与复核；启动、端口监听、浏览器打开和构建通过本身不等于交付。没有明确授权不 commit/push/deploy。
